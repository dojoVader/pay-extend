# Theme Rewrite

- Create a new theme in spa-next using the same Vue application but the UI should be from claude_theme/ui.webp
- Copy some of the from the apps/spa/src/views directory to the new theme, but make sure to update the styles and structure to match the claude_theme/ui.webp design.
- The following are to be copied from the apps/spa/src/views:
    - Dashboard
    - Dom selectors
    - extension-management
    - integrations
    - extension-logs
